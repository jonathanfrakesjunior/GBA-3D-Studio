# GBA-3D-Studio
A multifunctional multi game rom hacking tool for various supported 3D GBA Games.

In the next months the plan is to create a easy to use modding tool for various 3D GBA games.
After starting with GTA Advance Studio and Driv3r Advance Studio a Studio version for 
all released Velez & Dubail Dev. Team GBA games will follow.
When all projects are ready they will be compiled to GBA-3D-Studio.
And in the future more games will follow.

My goal is to make a intuitive nultifunctional tool for the romhacking and modding community
to open new possibilites for 3D-Games on GBA.
