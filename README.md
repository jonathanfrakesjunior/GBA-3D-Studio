# GBA-3D-Studio

**A multifunctional, multi-game ROM hacking tool for 3D Game Boy Advance games.**

> ⚠️ **Status: In development.** The first tools are being built now. Nothing here is final yet.

## About

Several GBA games pushed the hardware with real-time 3D, but modding them has always been hard and scattered across one-off tools.

GBA-3D-Studio aims to change that: one intuitive toolkit that gives the ROM hacking and modding community easy access to the assets and data of 3D GBA games, and opens up new possibilities for what these games can become.

## Roadmap

The project starts with individual game studios. Once they are ready, they will be merged into one combined tool.

| Phase | Goal | Status |
|-------|------|--------|
| 1 | **GTA Advance Studio** | 🚧 In development |
| 1 | **Driv3r Advance Studio** | 🚧 In development |
| 2 | A Studio for every released GBA game by the **Velez & Dubail Dev. Team** | 📋 Planned |
| 3 | **GBA-3D-Studio**: all studios combined in one tool | 📋 Planned |
| 4 | Support for additional 3D GBA games | 💡 Future |

## Goals

- **Easy to use.** A clear, intuitive interface, so you don't need to be a reverse-engineering expert.
- **Multifunctional.** Many editing tools in one place instead of many separate utilities.
- **Multi-game.** One workflow across all supported 3D GBA games.
- **Community-focused.** Built for romhackers and modders, and open to feedback.
